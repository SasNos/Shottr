# Status

## 10 November 2026: Mber Flow token sync, Figtree and Open Sans

- `src/theme.css` was a hand copy of Mber Flow 1.16.3. It is now generated by `npm run tokens` (`tools/tokens.mjs`,
  the same file as in Site Restyler and Honest Ratings) from Mber Flow 1.19.1; Figtree and Open Sans are in `fonts/`.
  The colors change with Mber Flow's new palette (brown accent and selection in light mode, warm grey panels).
- The non-token rules of the old `theme.css` (motion tokens, focus ring, reduced motion) moved to `src/base.css`,
  which also gives `h1`-`h3` the heading font; both pages load it after `theme.css`.
- The in-page colors of the selection bar and the toast follow the new palette; `test/inpage-theme.test.js` compares
  them with `theme.css`, so they cannot drift again unnoticed.
- `npm test` now enforces the coverage threshold itself (the separate `coverage` script is gone); `npm run check`
  runs lint, Prettier check, `tokens:check` and the tests, as in the other Spark tools. `CLAUDE.md` added.
- Tested: `npm run check` (201 tests, 100 % line, branch and function coverage). Not tested: the popup, the editor and
  the selection bar with the new colors and fonts in Chrome.
